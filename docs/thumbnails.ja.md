# 内容のサムネイル

日本語 | [English](thumbnails.en.md)

「内容のサムネイル」では、`.ai`、`.eps`、`.svg`、`.psd`、`.psb`、`.pdf` を拡張子ごとに選びます。「変更内容を確認」で有効化・復元する種類と関連する登録先を調べ、確認後に「選択を適用」で反映します。共有される関連付けでは、選択しない種類を含めて適用後の表示を示します。確認後に選択や登録が変わった場合は再確認が必要です。戻った後も下書きを保持し、「変更を破棄」で現在の登録に戻します。各行の適用状態はWindowsの登録を照合した結果です。アイコンの登録、既定アプリ、ファイルの内容は変更しません。

| 拡張子 | 内容の取得方法 |
| --- | --- |
| `.ai` | 確認できる埋め込みTIFFまたはXMPの画像を使用します。PDF互換データの描画は現時点では未対応です。 |
| `.eps` | 埋め込みTIFF、EPSIまたはXMPの画像を使用します。PostScriptの描画は行いません。 |
| `.svg` | SVGを描画します。外部リソースの取得は行いません。 |
| `.psd`、`.psb` | 対応する埋め込みサムネイルを使用します。 |
| `.pdf` | WindowsのPDF描画機能で先頭ページを表示します。 |

必要な画像がない場合や、形式・サイズの制限によって処理できない場合は、内容の画像を返しません。サムネイルの登録を無効にするには対象の選択を外して適用するか、「すべて元に戻す」を選びます。サムネイルの解除はアイコンの復元とは独立しています。

同じ関連付けを共有する種類では、現在確認できる共有先と元のサムネイル登録を記録し、選択しない種類も従来の提供元を使えるようにします。既定アプリや共有先、登録が外部から変更された場合は自動上書きせず、復元記録を保持します。マシン側の共有登録をユーザー側から抑止する組み合わせは未検証のため適用を中止します。変更途中に失敗した場合は詳細を確認し、「すべて元に戻す」を再試行できます。競合する組は保持され、復元可能なほかの組は先に戻します。

既定アプリが関連付けられていない拡張子は、その状態を記録してからサムネイルだけを登録します。その後に既定アプリが設定された場合も変更を検出し、自動で古い状態へ戻しません。

拡張子単独の登録を解除するときは、以前から実効関連付けとして使われていた同じProgIDが、ユーザー側の拡張子設定へ明示的に追加されただけなら、その追加値を保持してサムネイルだけを戻します。実効関連付けとほかの参照値が同一で、サムネイル登録も適用値または元の値に一致する場合に限ります。新たに既定アプリが設定された場合、別のアプリや参照先へ変わった場合、共有クラスを変更する組にはこの例外を適用しません。新しい適用と適用状態の確認は、引き続き記録との完全一致を要求します。

最後の組を解除するときは、元の登録を戻してから空の選択を保存し、最後に復元記録を削除します。保存や記録の削除に失敗した場合は復元記録を残して再試行できます。保存済みの選択が残っているのに復元記録が見つからない場合は、元の登録を推測できないため、新しい適用や設定の消去を中止します。

Explorerでの表示、既存ハンドラーとの共存、クラウド上のファイルの取得挙動と速度は、環境やファイルによって異なります。選択した種類のすべてのファイルにプレビューが含まれることや、表示速度を保証するものではありません。
