# アイコンパック取得の設計

0.1.0向けの取得・展開・変換の契約を定めます。取得・検証・展開・変換は `file-icons-catalog` が担当し、Shell DLLへ通信機能を持ち込みません。利用者のファイルや関連付けを変更せずに取得し、「適用する」は別操作にします。

## 配布元と更新

確認済み一覧にはvscode-icons 13.0.0、Material Icon Theme 5.39.0、Catppuccin Icons 1.26.0、Symbols 0.0.7、VSCode Great Icons 2.1.116を掲載します。Catppuccinは四つの配色を別の選択肢として保存します。作者のGitHubリリースにあるVSIXを取得し、Great Iconsは固定コミットの公式ソースZIPを使います。任意URL、MarketplaceのAPI、拡張機能の実行は使いません。JavaScriptやインストールスクリプトを実行しません。

Symbolsは公式の0.0.7を固定します。0.0.19には画像パス末尾の空白による不整合があります。0.0.26のVSIXには `*/actions/js` 等の複数階層を持つワイルドカード規則が含まれ、現在の親フォルダー規則の対応範囲を超えるため、取得対象にしません。

Great Iconsはv2.1.116が指す `71b1906d885ad0b7d65c0ad908fab43d9a61ea17` のソースZIPを固定します。GitHubリリースにはVSIXが添付されていないため、ソース内のテーマ定義と画像を読み取ります。配布物のSHA-256と展開後の識別情報の照合、通信・展開・変換の上限はVSIXと同じです。GitHub側のZIP生成方式が変わりバイト列が一致しなくなった場合も、ハッシュ照合を省略せず再確認して更新します。

この固定配布物の `icons/pnpm.svg` と `icons/singularity.svg` に限り、既知の標準SVG 1.1外部DTD宣言を文字列として一度だけ除去します。外部DTDの取得・解析や内部実体の展開は行わず、除去後も通常のSVG検査を通します。想定した宣言がない場合や、ほかのDTDが残る場合は取得を失敗させます。出典の `download.normalizations` へ対象パス、処理名、処理前後のSHA-256を記録します。通常の手元の取り込みでは、この前処理を行わずDTDを拒否します。

一覧には配布物のSHA-256、発行者、パッケージ名、版、テーマ識別子とリリースのタグ名を固定します。タグ名は版と分けて扱い、Symbolsの `0.0.7` のように `v` が付かないものもそのままURLへ使います。通信後の本文ハッシュと展開後の識別情報の両方を照合します。ハッシュは保守者が確認した配布物を固定するためのもので、作者の署名や安全性の独立した証明ではありません。更新時は素材の利用条件と互換性を再確認して一覧を更新します。上流の最新版を無審査で自動採用しません。

取得したパックの識別子には版を含めます。新しい版を取得しても以前の版と適用状態を保持し、明示的に適用します。確認済み一覧に新しい版が掲載された場合だけ「更新をダウンロード」を表示します。現段階では、上流の最新版の自動検出は行いません。

別版の選択設定は、取得済み一覧から明示的に下書きへコピーできます。同じ提供元・拡張・テーマに限って版の差分を表示し、対象の一致・追加・削除を確認できます。自動移行や旧版の自動削除は行いません。操作と保存の契約は[適用対象の選択](target-selection.ja.md#再取り込みと削除後の下書き)に従います。

変換中は使用する画像定義の完了件数と総数を通知します。同じ定義への参照は重複して数えず、複数テーマはテーマ番号と各テーマ内の件数を表示します。処理全体の経過時間を添え、件数から残り時間は推定しません。画像の変換完了後にも整合性検査と保存が残るため、画像の全件完了を取得処理全体の完了とは扱いません。

Symbols 0.0.7の公式VSIXには、未定義の `less` と `yml` を参照する規則があります。`fileNames`、`fileExtensions`、`languageIds` にある未定義アイコンへの参照だけを除外し、有効な規則で取り込みを続けます。除外した規則の種類、対象名、アイコン識別子をパックと出典の `warnings` へ保存します。この処理は公式取得と手元の取り込みで共通です。削除したファイル名規則は有効な拡張子規則などへ進み、対応する規則がなければWindowsの通常表示へ戻ります。対応規則が一つも残らない場合、画像自体の欠落、フォント型アイコン、安全性検査の失敗は取り込みを失敗させます。

## 資源と入力の上限

| 対象 | 上限・条件 |
| --- | --- |
| 通信本文 | 16MiB。Content-Lengthに加え、実際の読み取り量で制限する |
| 接続・リクエスト | 接続10秒、本文を含むリクエスト全体60秒 |
| 準備全体 | 180秒。読み取り・項目処理・素材変換の合間で確認する |
| リダイレクト | 最大3遷移。HTTPS・443番だけ。認証情報付きURLを拒否する |
| 通信先 | github.com、release-assets.githubusercontent.com、objects.githubusercontent.com、codeload.github.comのみ |
| ZIPの項目 | 最大12,000件、中央ディレクトリ4MiB。ライブラリによる項目確保の前に構造と実数を確認する |
| ZIPの展開 | 合計128MiB、1ファイル8MiB。申告値と実読量を照合する |
| 圧縮率 | 1項目の展開量は圧縮量の1,000倍＋1KiB以内 |
| 変換 | 1テーマ4,096種類以内、生成ICO合計128MiB以内。全テーマの生成結果も公開前に128MiB以内と照合する |
| 画像の寸法 | PNG・JPEG・SVG・ICO内画像は一辺4,096画素以内。PNG・JPEGのデコーダーの確保予算は64MiB |
| SVG | UTF-8のXMLを8MiB以内で解析します。XMLノード合計20,000、属性値・テキスト合計512KiB（画像のdata URLは除外）。DTDと圧縮SVGは拒否する |
| SVGの埋め込み | PNG・JPEGと子SVGに対応します。埋め込み画像と子SVGの合計16,777,216画素以内、入れ子は最上位を含め4段以内。壊れた埋め込み画像は無言で省略せず変換を失敗させる |
| ICOの入力 | 最大32フレーム、フレームの格納バイト数の合計32MiB、画素数の合計16,777,216以内。フレームの範囲・実際の寸法を領域確保前に確認する |
| 権利表示の収集 | 合計8MiB、256ファイルまで。読み取り中に制限し、JSONのエスケープ後も16MiBを超える前に中止する |
| 保存情報 | テーマ定義・出典は16MiB以内。権利表示の画面内表示は先頭32,000文字、完全な記録の所在も表示する |
| JSON5の構造 | パッケージ情報とテーマ定義は解析前に入れ子を64段以内へ制限する。文字列・コメント内の括弧は数えない |
| 同時操作 | 管理画面のロックと操作中の無効化で、取得を含め変更処理は一件ずつ |

HTTPの自動圧縮、環境のプロキシ、認証情報、Cookieを使いません。ZIPは暗号化・分割・ZIP64を拒否し、通常の格納とDeflateだけを受け付けます。上限は通常の公式配布物を取り込める範囲に設定したもので、任意の入力を安全と保証するものではありません。対応一覧とハッシュの固定も防御に含みます。

画像の上限は入力・寸法・個々のデコーダーに対する制限であり、GUIを含むプロセス全体の使用メモリーを64MiBへ強制制限するものではありません。SVGの複雑さも制限するが、OSによる単一の変換の強制打ち切りは行いません。確認済みの配布物の固定、内容検証、各上限を組み合わせます。

キャンセルは読み取り・展開・変換の合間で確認します。通信待ちや一つの画像変換を強制終了する仕組みではないため、即時停止は保証しません。通信待ちはリクエスト全体の上限で終了します。画面を閉じた場合も中断を要求し、背景処理が終わるまでは設定の同時変更防止ロックを保持します。

## 展開と保存

新規の一時領域へ展開します。絶対パス、親への移動、バックスラッシュ、ドライブ・代替データストリームを表すコロン、制御文字、末尾の空白・ドット、Windowsの予約名、大文字・小文字だけが異なる重複、リンクや特殊ファイルを拒否します。既存ファイルの上書きも許しません。画像変換では外部SVG参照を解決しません。

予約名はファイルと親ディレクトリの各パス要素で判定します。最初のドットより前の名前について、末尾のASCII空白とドットを除いた値を大小文字を区別せず照合し、`CON .txt` や `NUL .data/icon.svg` も拒否します。この処理は判定だけに使い、受け付けたパスの綴りを書き換えません。

一時の変換領域で全テーマを準備し、成功後に内容から決まる保存先へ移します。出典には取得URL、配布物のSHA-256、版、パッケージ情報、素材のハッシュ、権利表示とREADME、ICOへの変換内容を残します。権利表示は下位フォルダー、COPYRIGHT、THIRD_PARTY_NOTICES、licenses等のフォルダーとSEE LICENSE INの参照も含めます。相対パスを保持し、走査は12,000項目・深さ8までとします。リンクと拡張外への参照は拒否します。一時フォルダー名をパックの同一性へ含めず、再取得で同じ保存先を再利用します。既存コピーは内容を照合し、破損したコピーを上書きしません。手元の取り込みも同じ保存先・通常ファイルの検証を使用します。再取り込みでは元素材から再変換したICOと保存済みの内容を照合し、有効な別画像への差し替えも拒否します。画像・出典・保存フォルダーのリンクや再解析点を再利用しません。

名前から権利表示を探す際は、SVG、PNG、JPEG、ICO、GIF、WebP、BMPの画像を除外し、`license.png` のような見本画像を許諾文として扱いません。`SEE LICENSE IN` の明示参照とライセンス専用フォルダー内のファイルは拡張子で省略しません。これらにUTF-8で読めないファイルがある場合は、原文を無言で欠落させず取り込みを失敗させます。

変換方式の版はconversion_revision: 3として出典と保存先の同一性へ含めます。ICO入力は検証して復号し、16、20、24、32、48、128、256画素の出力へ再符号化します。入力に各サイズ用の描き分けがある場合は、必要な寸法を満たす最小のフレームを優先し、該当しなければ最大のフレームを使います。生成済みキャッシュも長さ、フレーム範囲、寸法を検査してから再利用します。

ICOの全フレームを順に復号して検査し、出力に必要な候補だけを保持します。使わないフレームの破損も拒否します。同じ面積の候補がある場合の順序と生成内容は維持し、変換方式の版は変更しません。

以前の変換結果は上書きせず保持し、既存の適用状態を自動変更しません。過去の開発版で取得したパックに新しい変換方式を適用する場合は、未適用のものを削除して再取得するか、元の拡張から再取り込みします。適用中の場合は先にWindows標準へ戻します。以前の版が保存した素材の内容を、この変更だけで再検査済みとは扱いません。

一覧の保存前に失敗した場合、適用状態は変えません。一時領域は通常終了時に除去します。設定の保存失敗やプロセスの強制終了によって、一覧から参照されない生成素材が残る可能性はあります。参照されないフォルダーを一括で再帰削除する処理は行いません。

削除は一覧と削除保留の記録を先に保存します。適用中、ほかのパック、元のアイコンの復元情報が参照する素材を保持します。所有するハッシュ名のフォルダー内にある既知の通常ファイルだけを削除し、未知のファイルやリンクを見つけた場合は保留します。元の読み込みフォルダーとShell DLLはパック削除の対象にしません。

## 検証

通信を伴わない試験では、自作素材のVSIXを本番と同じ検証・展開・変換へ通します。改変、識別情報の不一致、パス脱出、予約名、重複、リンク、過大な項目・展開、時間切れ、中断、再取得時の同一性、権利表示の保持を確認します。

GUIはGPUIのtest-supportで、本物のボタンと入力欄を操作します。通信成功・失敗を差し替えるが、成功時のZIP検証とICO変換は実処理を使います。実通信の確認は次を別途実行します。

```powershell
cargo test -p file-icons-catalog --locked -- --ignored --exact tests::official_releases_download_and_compile --nocapture
```

実Explorerへの適用はこの試験に含みません。登録・復元は専用レジストリでのShell結合試験、実Explorerでの見え方は別の受け入れ検証で扱います。
