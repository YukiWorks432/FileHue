# 変更履歴 / Changelog

公開版の変更履歴を0.1.0から記録します。日付は日本時間（UTC+09:00）です。

Public release history starts at 0.1.0. Dates use Japan Standard Time (UTC+09:00).

## 0.2.0 — 未公開 / Unreleased

内容サムネイルの追加、保護設定とパック取得の操作改善、設定を維持するアイコン用DLLの更新、関連付けの修正と依存更新を含みます。最新mainの実装を基にした[日本語のリリースノート案](docs/releases/0.2.0.ja.md)と[English draft](docs/releases/0.2.0.en.md)を用意しています。公開日と最終的な対応範囲は、配布候補の検証後に確定します。

Changes include content thumbnails, improved protection and pack-download workflows, icon DLL updates that preserve settings, association fixes, and dependency updates. The drafts above describe the latest main implementation; the publication date and final supported scope remain subject to release-candidate validation.
