# ローカルTLS試験の証明書

`localhost-cert.pem` と `localhost-key.pem` は、自己署名証明書を拒否する契約試験だけに使う公開の試験データです。秘密鍵を含みますが、製品・利用者・認証局の実際の鍵ではありません。製品の信頼する証明書へ追加しません。

証明書の名前は `localhost` と `127.0.0.1`、有効期間は2020年から2040年です。Windowsの.NET `CertificateRequest` でRSA 2048ビットの鍵を作り、SHA-256で自己署名しました。ローカルの試験サーバーがこの証明書を提示し、製品の取得クライアントが未知の発行者として拒否することを確認します。外部通信や証明書ストアの変更は行いません。
